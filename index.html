MineTUKI

Modpack de Minecraft 1.21.1 · NeoForge

Descargar

Funciona en Windows, Mac y Linux. No necesitas tener Java instalado.

Descargar

Cómo se usa

  1. Cierra el launcher de Minecraft. Si está abierto puede borrar el perfil que se va a crear.
  2. Descomprime el archivo y abre el instalador de tu sistema:
    instalar-windows.bat o instalar-mac-linux.command.
  3. Elige el idioma.
  4. Deja marcada la primera opción y pulsa Instalar.
  5. Abre el launcher y elige el perfil MineTUKI.

Crea una carpeta de mods propia: no toca los mods que ya tengas en otros perfiles. Se ejecuta una sola vez — después el juego avisa solo cuando el modpack cambia.
